# paper/

Manuscript drafts, figures and anything else destined for the write-up.

**Contents of this folder are deliberately not version-controlled.** The folder
itself is tracked so the path exists on a fresh clone; everything inside is
ignored by `.gitignore` except this README. Keep drafts here rather than in
`docs/`, which *is* tracked.

Figures for the manuscript are regenerated from `results/paper/` — see the
README there for which benchmark run each number comes from.
